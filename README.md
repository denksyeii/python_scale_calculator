# MetricMeowl - Scale Calculator Desktop (v1.2)

> A dedicated calculation desktop application built to transform architectural or engineering plan measurements between different scales (from 1:x to 1:y). Users provide the baseline measurement and both scale factors to obtain the accurate converted value. Additionally, it features an integrated unit converter to streamline workflow.
>
> Aplicación de escritorio diseñada para convertir medidas de planos técnicos entre diferentes escalas (de 1:x a 1:y). Permite ingresar la medida original junto con ambas escalas para obtener la dimensión convertida. Incluye además un conversor de unidades integrado para facilitar los cálculos.
